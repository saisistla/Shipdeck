# UI & UX

An excellent user experience. First understand the project, then do an excellent UI and UX. It should be 10/10, with the best colour combinations, and should be an enterprise demo level.

Do not delete any code, connections, or history. Change only UI and UX.

## Steps

1. Read the product before restyling it: who it is for, the main path, and the words already on screen.
2. Judge it as a first-time user. Every screen should say what it is, what to do next, and what a control will change.
3. Restyle in place. Keep every feature, route, saved connection, secret, and run history.
4. Use one calm enterprise palette: warm paper background, deep ink sidebar, one navy action colour, brass only for “this is real / live”. Status colours stay green, amber, and red.
5. Replace insider labels with plain ones. Keep the underlying behaviour and data fields.
6. Check the main path in the browser: empty state, a filled screen, and both light and the live/practice control.

## Do not

- Delete or rewrite `data/store.json`, `data/secrets.enc`, `data/delivery.json`, or run history.
- Remove buttons, forms, or API calls while “cleaning up” the UI.
- Introduce a second accent colour for decoration.
